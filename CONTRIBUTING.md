# Участие в разработке Numismat

Спасибо за интерес к проекту. Numismat работает с финансовыми данными, поэтому изменения должны быть небольшими,
проверяемыми и безопасными по умолчанию.

## Перед началом

1. Создайте issue для заметного изменения поведения или схемы данных.
2. Не добавляйте реальные Telegram updates, токены, ID владельца, дампы и финансовые данные.
3. Сохраняйте независимость `domain` и `application` от aiogram, SQLAlchemy и adapter-слоя.
4. Для денег используйте integer minor units; `Decimal` допустим только на границе ввода, `float` запрещён.
5. Любое изменение схемы оформляйте Alembic migration.

## Локальная проверка

```bash
uv sync --frozen
make check
docker compose config --quiet
```

Новая функция требует unit-теста. PostgreSQL integration-тест должен работать только с БД, имя которой заканчивается
на `_test`, и не должен молча пропускаться.

## Pull request

- объясните пользовательский эффект и выбранное решение;
- перечислите выполненные проверки;
- обновите `README.md`, `SPEC.md`, `SECURITY.md`, `DECISIONS.md` или `PLAN.md`, если контракт изменился;
- не смешивайте независимые рефакторинги и продуктовые изменения;
- убедитесь, что JSON-логи не содержат Telegram ID, суммы, описания, message text, credentials или URL с паролями.

Сообщения об уязвимостях не публикуйте в открытом issue — используйте процесс из [SECURITY.md](SECURITY.md).
